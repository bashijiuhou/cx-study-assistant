# CX Study Assistant 🎓

> 超星学习通自动刷课助手 — 自建题库 + AI 智能答题 + 视频/音频倍速 + 空白页卡死自愈

## ✨ 功能特性

### 自动刷课
- 🎬 **视频/音频倍速** — 自动播放并锁定倍速；超星禁用倍速的视频自动回退 1×（防进度清空），临近结尾自动恢复 1×（防任务点判定失败）
- 📖 **任务全覆盖** — 视频、音频、文档、阅读、读书、直播、速课自动处理，测验/作业自动作答
- 🔁 **自动翻页跳章** — 课时内多页自动翻页，处理完自动跳下一章节，闯关/未开放章节自动停下等人工处理
- 💤 **后台防休眠** — 静音 AudioContext 维持播放，缓解浏览器后台标签页节流导致的进度回退

### 卡死自愈（v3.4.2 新增）
- ⏱️ **视频循环限时** — 每轮重新获取 iframe document（修复 iframe 重载后旧引用永久查不到视频的无限卡死）；4 分钟没加载出先重载任务框架，再 2 分钟仍空白自动跳过该任务
- 🐕 **卡死看门狗** — 每 30 秒巡检：页面整页空白超 2 分钟、或视频任务超 8 分钟无任何播放进度 → 自动刷新整页恢复刷课（默认启用，闯关模式等人工介入场景已排除，不会误刷新）

### AI 智能答题
- 🤖 **5 个模型可选** — NVIDIA Nemotron 3 Super 120B（推荐 ⚡）/ DeepSeek V4 Flash / GPT-OSS 20B / Nemotron 3.5 Lightning / Nemotron 3 Ultra，走自建 New-API 后端，默认模型开箱即用，其余填自己的 OpenAI 兼容 Key 即可
- 🔄 **答案自动回写** — AI 生成的答案自动存入题库，越用越准
- ⏳ **限流退避** — AI 请求 429/5xx/超时自动指数退避重试，可选搜题间隔节流
- 🛡️ **Frame 白名单** — 只在功能页注入，杜绝多 iframe 重复面板、重复答题

### 自建题库
- 📚 **PostgreSQL 题库** — 题干精确匹配 + 选项 Jaccard 相似度匹配，配 Web 管理后台
- ✏️ **答案修正** — 题库答案有误一键修正，修正结果优先级最高
- 🔎 **答题核对模式** — 提交测验后自动从详情页抓公布答案：与题库不一致自动修正（存选项文本防换位错位），题库未命中的新题自动入库
- 📊 **置信度分级** — `human`（手动修正）> `network`（外部导入）> `model`（AI 生成），高优先级覆盖低优先级

### 稳定性
- 🔐 **GM 存储设置** — 跨超星多个子域共享一份设置，API Key 不暴露给页面 JS，旧 localStorage 设置自动迁移
- 🧯 **容错兜底** — iframe 等待限时、题目加载超时跳过、未知题型跳过，任何单点异常都不会卡死整条自动流程

## 📦 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装链接](https://raw.githubusercontent.com/bashijiuhou/cx-study-assistant/cx-study-%E5%80%8D%E9%80%9F/cx-study-assistant.user.js)，Tampermonkey 自动弹出安装提示
3. 点击「安装」

或手动安装：打开 Tampermonkey → 新建脚本 → 粘贴 `cx-study-assistant.user.js` 内容 → `Ctrl+S` 保存

## 🚀 使用

### 首次配置

1. 打开 [超星学习通](https://mooc1.chaoxing.com/) 并登录，左侧出现脚本控制面板
2. 使用默认模型（Nemotron 3 Super）**无需任何配置**，开箱即用
3. 想换其他模型：点「设置」→ 填写你自己的 OpenAI 兼容 API Key（支持 New-API / One-API 等自建服务或任意中转，需支持 `/v1/chat/completions`）

> 配置保存在油猴 GM 存储中，跨子域共享，下次无需重复填写。

### 控制面板

| 设置项 | 说明 |
|--------|------|
| 模型选择 | 5 种模型切换（默认 Nemotron 3 Super ⚡，无需自备 Key） |
| 倍速 | 视频/音频播放倍速 |
| 搜题间隔 | 两次 AI 请求最小间隔，防限流 |
| 测验自动提交 | 有答案时自动提交 |
| 强制提交 | 无答案也提交（谨慎） |
| 答题核对模式 | 提交后抓公布答案核对题库，错题自动修正、新题自动入库 |
| 重做模式 | 不跳过已答题，重新作答覆盖 |
| 好学生模式 | 仅加粗/插入答案不自动选择，适合手动核对 |
| 相似度匹配 | 精确匹配失败时模糊搜索题库 |
| AI API Key | 切换非默认模型时必填 |

### 使用流程

```
登录超星 → 进入课程 → 打开任务点（全自动）
 ├─ 视频/音频 → 自动播放 + 倍速 + 空白页自愈
 ├─ 作业/测验 → 题库查询 → 未命中则 AI 作答 → 回写题库 →（可选）提交后核对公布答案
 ├─ 考试 → 同作业流程（可开启自动跳转）
 ├─ 文档/PPT → 自动翻阅
 └─ 直播 → 自动按时长上报
卡死看门狗全程巡检，页面空白/播放停滞自动刷新恢复
```

## ⚠️ 注意事项

- 倍速过高可能被超星判定异常，建议 ≤ 2×；禁用倍速的视频脚本会自动回退 1×
- AI 答案非 100% 正确，建议开启「好学生模式」或「答题核对模式」自行核对
- 开启「强制提交」前请确认，空题也会直接提交
- 仅供学习交流，请合理使用
