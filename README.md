# CX Study Assistant 🎓

> 超星学习通自动答题助手 — 自建题库 + AI 智能答题 + 视频倍速

## ✨ 功能特性

- 📚 **自建题库** — PostgreSQL 驱动，题目精确/模糊匹配，支持 Web 管理后台
- 🤖 **AI 智能答题** — 多模型可选（DeepSeek V4 Flash/Pro、Kimi K2.6、GLM-5.1、MiniMax M2.7、Gemma 3）
- ✏️ **答案修正** — 题库命中答案有误？一键修正，修正答案优先级最高
- 🔄 **AI 答案自动回写** — AI 生成的答案自动存入题库，越用越准
- 🎬 **视频/音频倍速** — 最高 16 倍速，支持复习模式补挂时长
- 🎯 **答案插入题目** — AI 答案直接显示在题目文本后方，方便核对
- ⚙️ **可配置 API Key / Token** — 设置面板内直接修改，无需改代码

### 置信度体系

题库答案按来源分级，高优先级覆盖低优先级：

| 置信度 | 来源 | 说明 |
|--------|------|------|
| `human` | 手动修正 | 最高优先级，点击 ✏️ 修正后写入 |
| `network` | 外部导入 | 批量导入的题目 |
| `model` | AI 生成 | AI 答题自动回写，优先级最低 |

## 📦 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装链接](https://raw.githubusercontent.com/bashijiuhou/cx-study-assistant/feature/question-bank/cx-study-assistant.user.js)，Tampermonkey 自动弹出安装提示
3. 点击「安装」

或手动安装：打开 Tampermonkey → 新建脚本 → 粘贴 `cx-study-assistant.user.js` 内容 → `Ctrl+S` 保存

## 🚀 使用

1. 打开 [超星学习通](https://mooc1.chaoxing.com/) 并登录
2. 进入课程任务页面，左侧出现脚本控制面板
3. 选择 AI 模型 → 脚本自动运行

### 控制面板

| 设置项 | 说明 |
|--------|------|
| 模型选择 | 6 种模型切换（推荐 DeepSeek V4 Flash ⚡） |
| 视频/音频倍速 | 1× / 1.25× / 1.5× / 2× |
| 搜题间隔 | 两次 AI 请求最小间隔，防限流 |
| 测验自动提交 | 有答案时自动提交 |
| 测验强制提交 | 无答案也提交（谨慎） |
| 考试自动跳转 | 考试模式自动下一题 |
| 答案加粗不选择 | 只标注不自动选择 |
| 答案插入题目后 | AI 答案显示在题干后方 |
| 重做模式 | 不跳过已答题，AI 重新作答覆盖 |
| 相似度匹配 | 精确匹配失败时模糊搜索题库 |
| AI API Key | 自定义 API Key（留空用默认） |
| 题库 Token | 自建题库认证 Token（留空用默认） |
| 📚 题库管理后台 | 跳转 Web 管理页面 |

### 使用流程

```
登录超星 → 进入课程 → 打开任务点
 ├── 视频/音频 → 自动播放 + 倍速
 ├── 作业 → 题库查询 → 未命中则 AI 答题 → 答案回写题库
 ├── 考试 → 同作业流程（可开启自动跳转）
 └── PPT → 自动滚动浏览
```

### 答案修正

发现题库答案有误时，点击答案旁的 ✏️ 修正按钮，输入正确答案即可覆盖。修正后置信度为 `human`，后续查询优先返回。

## 🛠 自建题库 API

题库部署在阿里云服务器，FastAPI + PostgreSQL，提供以下接口：

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/query` | POST | 查询题目（精确/模糊匹配） |
| `/api/upsert` | POST | 新增或更新题目 |
| `/api/batch-upsert` | POST | 批量写入 |
| `/api/search` | POST | 模糊搜索 |
| `/api/questions/{id}` | GET/PUT/DELETE | 单题 CRUD |
| `/api/stats` | GET | 题库统计 |
| `/admin` | GET | Web 管理后台 |

> 题库 API 需要 Bearer Token 认证，可在脚本设置面板配置。

## ⚠️ 注意事项

- 倍速 > 4× 可能导致进度重置，建议不超过 4 倍速
- AI 答案非 100% 正确，建议开启「答案插入题目后」自行核对
- 开启「强制提交」前请确认，空题也会直接提交
- 仅供学习交流，请合理使用
